我们提供“策略研究咨询”服务。
在不涉足企业对产品的顶层商业策略情况下，从设计层面重新思考，发挥设计思维的优势——深入洞察用户需求与使用场景，发掘产品可创新空间，并通过对行业理解与生产工艺的融合将产品落地实现量产。

  • 产品诊断 Product diagnosis

    通过对行业发展趋势的精准捕捉，基于当前社会、政策、经济及技术发展，为客户现有产品未来发展方向指明道路。以商业视角挖掘用户潜在需求与商业机遇，前瞻性引导企业战略。

  • 商业机会洞察 Business insight

    我们的使命是找出阻碍产品与用链接的矛盾并发展可扩展性。我们对产品进行定性与定量分析创新可行性分析，为项目搜寻与之匹配的技术加工合作方，迅速建立产品在市场的独特商业地位。

  • 行业趋势分析 Industry trend analysis

    行业趋势分析是关于由国家或国际行业分类系统定义的特定经济活动部门的定性和定量报告。内部多领域团队合作，精准捕捉可行性数据，科学地降低开发成本并加速项目进度。

  • 用户行为研究 Research on user behavior

    用户研究的重点是通过观察技术，任务分析和其他反馈来了解用户的行为，需求和动机。我们秉承功能、理性、情感的设计哲学，用户使用流程进行全方位分析，寻找产品突破点切入市场。

  • 产品线规划 Product line planning

    产品线是一组相关产品，全部以同一品牌出售，并由同一公司出售。大业以精准分析产品形式，精准匹配客户需求，通过对产品的深刻理解进行与其风格匹配的产品线规划。

  • 产品DNA构建 Product DNA construction

    视觉产品语言是为品牌烙印的独特“字母”，设计师通过在现有产品的基础上，基于原型与外观方案，结合跨学科知识进行产品内部结构合理优化并控制成本，确保产品量产落地与安全使用。

  • 风险与控制 Risk and control

    风险控制是企业评估潜在损失并采取行动减少或消除此类威胁的一套方法。我们对产品内部结构进行原理图设计，优化内部的布局，合理的放置顺序，充分考虑产品在使用过程中的安全性。

我们擅长用从构思到商业化的一系列战略和设计思路来构建产品。
无论您是寻求企业的转型升级，还是持续打造创新的产品爆款，选择大业您都会得到：从企业诊断、产品创新、品牌构建、传播推广、生产落地等多位一体的产品设计服务。

  • 技术跨领域匹配 Technology matching

    通过多年跨行业经验积累，基于新技术突破，专注于不同技术研发应用；以一针见血的方式发现产品痛点，摆脱传统设计思维禁锢，技术迭代推动产业迭代，为企业提供持续品牌领航力。

  • 原型堆叠创新 Prototype innovation

    通过对企业的深度了解与沟通，迅速了解产品内部堆叠原理，设计师与结构人员共同探讨不同堆叠模式的创新，重新定义产品。创造完全不同的产品类型。

  • 产品外观设计 Product design

    基于平衡商业、用户、技术三个方面的需求，将使用候选设计构建非功能性外观模型。该产品以其设计的外观和功能来表达个性或讲述故事。

  • CMF工艺 CMF process

    旨在通过其使用环境的分析及调研，通过CMF的应用，达到令产品融入环境的目的。同时，积极寻找新型材料，力图解决产品因为材料受限的功能与痛点。

  • UI / UX交互 UI / UX interaction

    是用户与产品之间交互的设计。通常，当人们谈论交互设计时，产品往往是诸如应用程序或网站之类的软件产品。交互设计的目标是创建使用户能够以最佳方式实现其目标的产品。

  • 包装与说明书 Package and instruction

    仅仅产品美观是源源不够的，包装也要足够吸引才能提升产品的销量。而包装必须提供独特的东西才能真正吸引顾客，独特性可以通过几种不同的方式体现出来。

  • 手板验证 Prototype verification

    具备集团化手板厂下游产业，当您确定需要解决的用户问题时，便会进行手板验证，验证其内部堆叠及部分解决方法是否可行。这是产品落地的后期阶段。

  • 样机测试 Prototype test

    就是针对样机做相关的性能测试。一般有机械性能、电子电气性能等。一般分为功能样机与外观样机，功能样机需验证其核心功能的运行情况；外观样机需验证其生产落地性。

  • 安规认证 Safety certification

    配合产品进行安全规定认证（如CCC/CE/GS），为产品安全落地向全球目标市场所属地有关部门进行申报，调试，过检。安规认证 是基於保护使用者和环境安全和质量的一种产品认证。
